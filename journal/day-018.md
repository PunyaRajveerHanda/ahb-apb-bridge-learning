## 1. APB Transfer Phases

An APB transfer mainly consists of two phases:

### SETUP Phase

During the SETUP phase:

- `PSEL = 1`
- `PENABLE = 0`
- Address is placed on `PADDR`
- `PWRITE` indicates whether the operation is a read or write
- For a write transfer, valid data is placed on `PWDATA`

The SETUP phase always lasts for **one clock cycle**.

### ACCESS Phase

On the next clock cycle, the transfer enters the ACCESS phase:

- `PSEL = 1`
- `PENABLE = 1`

The transfer completes when:

```text
PSEL = 1
PENABLE = 1
PREADY = 1
```

If `PREADY = 0`, the ACCESS phase is extended.

Therefore, an APB transfer requires a **minimum of two clock cycles**:

```text
SETUP → ACCESS
```

---

## 2. Write Transfer Without Wait States

For an APB write operation:

```text
PWRITE = 1
```

During the SETUP phase, the master provides:

- `PADDR`
- `PWDATA`
- `PWRITE = 1`
- `PSEL = 1`

and keeps:

```text
PENABLE = 0
```

On the next clock cycle, the ACCESS phase begins:

```text
PENABLE = 1
```

If the slave keeps:

```text
PREADY = 1
```

the transfer completes at the end of that ACCESS cycle.

### Sequence

```text
IDLE → SETUP → ACCESS → COMPLETE
```
