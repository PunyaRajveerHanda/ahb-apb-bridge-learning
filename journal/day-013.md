## Key understanding

The master uses address and control signals to describe a transfer,
while write data belongs to its corresponding data phase.

For the SINGLE word-write example:

- HBURST = 3'b000 selects SINGLE.
- HSIZE = 3'b010 selects a four-byte transfer.
- HTRANS = 2'b10 identifies a NONSEQ transfer.
- HWRITE = 1 selects a write operation.

Studied how the state register and next-state logic work together,
and how HREADY affects transfer progress.

Also examined how local FIFO storage can buffer data separately
from the AHB bus interface. The request inputs used by the example
are local controls, rather than additional standard AHB signals.
