## Key concepts studied

INCR4 describes four incrementing transfers. The example uses
HBURST = 3'b011, with NONSEQ for the first transfer and SEQ for
the following transfers.

For word-sized transfers, consecutive addresses differ by four bytes.
The notes examine how a counter and FIFO read pointer relate to
the data being supplied, and how the example returns to IDLE.

Studied how a testbench connects the master to a simple slave and
drives local request inputs separately from the AHB interface signals.
