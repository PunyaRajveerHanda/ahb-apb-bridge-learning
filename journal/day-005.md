## Review corrections to read alongside the photos

- State diagram: add ACCESS -> ACCESS while PREADY=0. Exit ACCESS only when PREADY=1: go to IDLE if there is no next transfer, otherwise SETUP. SETUP lasts exactly one cycle and always advances to ACCESS.
- Page 2: explicitly write PENABLE=0 in SETUP; its value was omitted.
- Pages 3 and 6: label the waveforms as no-wait examples with PREADY=1, or draw PREADY explicitly.
- Page 4: correct the write explanation's extra cycle. SETUP is T2–T3 and ACCESS is T3–T4. With PREADY=1 the write completes at rising edge T4. PENABLE falls after that edge; PSEL falls if the bus goes idle. The waveform does not show another ACCESS cycle during T4–T5.
- Write address, direction, selection and write data must be valid in SETUP and remain stable until completion, including any ACCESS wait cycles.
- Page 6: the read completes at rising edge T4 under the no-wait assumption. PRDATA must be valid by that completing edge and may become valid earlier. Successful completion additionally assumes no error response.
- Page 5: replace the abbreviation AMB with AHB. APB is itself part of AMBA.
- An IDLE cycle is optional between transfers. A subsequent transfer always needs a new SETUP cycle with PENABLE=0; PSEL can remain asserted for the same peripheral.
